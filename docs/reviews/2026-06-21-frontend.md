> Fix ad alto impatto, basso rischio. Iniziare da qui.

## 1.1
📄 `components/feature/acquisti/AcquistiContent.tsx:196-219`
🏷️ [Bug UI]
🚨 Alta
🔍 `useState` inizializzato con `new Date(Date.now() - 5*86400000).toISOString()`. Next.js App Router SSR-a i `'use client'`: server calcola `Date.now()` a T, client a T+δ → `shippedAt` divergente → hydration mismatch (flash + CLS).
💡
```tsx
const [mockShippingOrders, setMockShippingOrders] = useState<MockShippingOrder[]>([]);
useEffect(() => {
  setMockShippingOrders([
    { /* ... */ shippedAt: new Date(Date.now() - 5*86400000).toISOString(), status: 'in_transit' },
    { /* ... */ shippedAt: new Date(Date.now() - 18*86400000).toISOString(), status: 'delivered' },
  ]);
}, []);
```

## 1.2
📄 `components/feature/scambi/ScambiDetailView.tsx:24-27, 65-68`
🏷️ [Bug UI]
🚨 Alta
🔍 `Math.random()` dentro `useMemo` in render. Server e client producono shuffle diversi → sezione "card simili" mismatch.
💡
```tsx
const [similarCards, setSimilarCards] = useState<ScambioUI[]>([]);

  setSimilarCards(getRandomScambi(getScambiCatalog(), scambio?.numericId ?? -1, 3));
```

## 1.3
📄 `lib/hooks/useFixedSidebarFooterClamp.ts:22-25`
🏷️ [Bug UI]
🚨 Alta
🔍 `useState(() => ({ maxHeight: typeof window !== 'undefined' ? window.innerHeight - defaultTop : 600 }))`. Server → `600`, client → `window.innerHeight - defaultTop` → stile inline divergente.
💡
```tsx
const [style, setStyle] = useState<FixedSidebarClampStyle>({ top: defaultTop, maxHeight: 600 });
useEffect(() => {
  const update = () => setStyle({ top: defaultTop, maxHeight: window.innerHeight - defaultTop });
  update();
  window.addEventListener('resize', update);
  return () => window.removeEventListener('resize', update);
}, [defaultTop]);
```

```ts
export function useTimeoutFn() {
  const ref = useRef<ReturnType<typeof setTimeout> | null>(null);
  const set = useCallback((fn: () => void, ms: number) => {
    if (ref.current) clearTimeout(ref.current);
```
